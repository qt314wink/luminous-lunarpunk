# ✦ Luminous Lunarpunk

> *Defiant folklore reassembly through stained glass, kintsugi, and botanical myth.*

An interactive generative web experience exploring the fracture and repair of primordial goddesses through layered visual systems. Built as a single-page HTML canvas work with GSAP scroll animations.

## What It Does

- **Mosaic Engine** — A full-screen procedural stained-glass tile system with leading (black grout lines) and glass color variation
- **Botanical Engine** — Mouse-reactive vines that grow, branch, and bloom in teal and jade
- **Kintsugi SVG Cracks** — Animated golden fracture lines that reveal themselves across the screen with glowing drop shadows
- **Luminescent Particles** — 60 gold and sage particles drifting in bioluminescent loops
- **Fragment Grid** — An interactive goddess reassembly mechanic with chime audio feedback
- **GSAP ScrollTrigger** — Section reveals with parallax and stagger animations
